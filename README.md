# PW Civil AE/JE Lecture Tracker

Self-contained lecture progress tracker for the Civil AE/JE (Ashoka 2026) tech subjects.
Hosted on GitHub Pages — works on any device, fully offline-capable.

- Mark lectures: to-do / done / skipped
- Live stats: hours left, days to finish, estimated completion date (set daily hours + playback speed)
- Cloud sync across devices via a private GitHub gist (paste a gist-scoped token once per device)

Progress is stored in browser localStorage; use the sync panel or Export button for backups.
